# Nyzeep 主页重设计：实现决策

本文件将用户提供的参考主页效果与 Nyzeep 的最终实现一一对应，说明哪些被复现、哪些被有意省略，以及原因。

## 参考效果到最终实现

| 参考实现 | Nyzeep 的实现 | 决策理由 |
| --- | --- | --- |
| 首屏打字机与 GIF 建立氛围 | 一个自托管的 [nyzeep-terminal.svg](../../assets/nyzeep-terminal.svg) 开发工作台动效 | 复现首屏主题化动效的节奏，但避免叠加多个远程动态图。它是装饰性图像，核心资料以 README 正文提供。 |
| 亮暗主题的贡献蛇 picture | README 末尾继续使用亮暗两张蛇 SVG 与 picture 回退 | 直接保留参考中最有记忆点的效果，并沿用已验证的 output 分支发布模式。 |
| 参考中的 3D 贡献图、日历、活动图、Metrics 图集 | 不加入 | 它们与蛇重复表达贡献事实，也会增加图片请求与维护负担。 |
| 参考中多份都在整点运行的工作流 | 蛇任务调整为 03:17 UTC，并使用 contribution-snake-output concurrency 组 | 避开整点高负载并防止多个写入触发器竞争 output 分支。 |
| 浮动第三方 Action 版本 | 用审查时解析的完整 SHA 固定 | 保留当前 v3/v4 行为，同时降低可移动标签带来的供应链风险。 |

## 信息架构

1. 首屏：一个装饰性本地 SVG 和两个真实 GitHub 入口。
2. 核心：两个可审计的精选项目；Ecoscout 与 LumiMate 作为轻量探索链接。
3. 技术：七个公开仓库语言端点可支撑的核心技术图标。
4. 证据：Stats 与 Top Languages 两张辅助卡；语言卡明确不代表熟练度。
5. 趣味：底部绿墙蛇是唯一大型贡献可视化。

## 证据与维护

- 项目定位、许可证和技术标签的来源记录在 [nyzeep-public-portfolio.md](nyzeep-public-portfolio.md)。
- 外部图像服务并不承载必要身份信息；即使某一张卡片不可用，正文项目链接仍完整可读。
- 若精选项目、描述或技术栈变化，应同时更新 README、证据档和本决策记录。
