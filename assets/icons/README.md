# Brand icon sources

These 12 SVGs are unmodified copies from [Simple Icons 16.35.0](https://github.com/simple-icons/simple-icons/releases/tag/16.35.0), published on 2026-10-11 and retrieved on 2026-10-13.

Pinned upstream commit: [`ed9a5192b24ad2f169bf1009931da0df27d5a49a`](https://github.com/simple-icons/simple-icons/commit/ed9a5192b24ad2f169bf1009931da0df27d5a49a).

Every file is copied byte for byte from `icons/<slug>.svg` at that commit. No logo was drawn, recolored, or otherwise modified locally. All files use the upstream `0 0 24 24` view box. Colors below are upstream brand metadata, not edits to the SVGs.

## Reproduction and integrity

Use this immutable URL pattern, replacing `<slug>` with a filename stem from the table:

```text
https://raw.githubusercontent.com/simple-icons/simple-icons/ed9a5192b24ad2f169bf1009931da0df27d5a49a/icons/<slug>.svg
```
